🎨 Anime Coloring — раскрась аниме-персонажа в консоли

> «Твоя кисть — это ASCII»

**Anime Coloring** — это набор консольных утилит для генерации раскрашенных аниме-персонажей в ASCII-графике с использованием ANSI-цветов.  
Вы можете выбрать цвета для волос, глаз, кожи, одежды и аксессуаров, и программа выведет цветной ASCII-арт с вашими настройками.

## 🚀 Особенности
- 🎨 Настройка цветов для каждой части персонажа: волосы, глаза, кожа, одежда, аксессуары.
- 🖌️ Поддержка 16 стандартных цветов (red, green, blue, yellow, magenta, cyan, white, black и т.д.).
- 🖥️ Вывод цветного ASCII-арта прямо в терминал.
- 🎛️ Аргументы командной строки для быстрой смены цветов.
- 🔄 Интерактивный режим с пошаговым выбором цвета (где реализовано).
- 💾 Сохранение результата в текстовый файл с ANSI-кодами (опционально).
- 📦 Кросс-платформенность: работает на всех ОС с поддержкой ANSI (Linux, macOS, Windows 10+).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python anime_coloring.py`              |
| Go         | стандартная библиотека               | `go run anime_coloring.go`              |
| JavaScript | Node.js (без внешних модулей)        | `node anime_coloring.js`                |
| Java       | стандартная библиотека               | `javac AnimeColoring.java && java AnimeColoring` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `colored` (crates)                   | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby anime_coloring.rb`                |
| PHP        | стандартная библиотека               | `php anime_coloring.php`                |
